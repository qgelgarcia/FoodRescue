# Deliver the member app as an Android APK

The school-defense member experience is delivered as an Android APK for donors and claimants. The admin panel is accessed in a desktop browser. A browser-only member demonstration is not sufficient for the agreed delivery target.

We chose the APK requirement over relying on a mobile HTTPS web app because the user explicitly requires the mobile app to be an APK. Camera-based QR verification, foreground location sharing, photo uploads, and shared updates must therefore be verified on the Android delivery target. Background journey tracking remains deferred.
