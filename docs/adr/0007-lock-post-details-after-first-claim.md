# Lock post details after the first claim

Once any claim has been submitted, the donor may no longer edit the post's food details, total quantity, pickup location, or pickup deadline. This remains true even if that claim is later rejected or cancelled. Changing these arrangements requires explained cancellation of the existing post and creation of a new post.

We chose fixed arrangements over the original rule allowing edits before acceptance and deadline shortening afterward because claimants make plans based on the offered details. In particular, shortening an agreed deadline could invalidate an anticipated pickup. Inventory and lifecycle transitions remain separate from donor edits.
